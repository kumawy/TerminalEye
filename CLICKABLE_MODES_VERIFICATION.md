# Кликабельные режимы · 0.3

Проверка 22 октября 2026 на macOS 26.6.2 arm64, Python 3.12.14, tmux 3.8.

Готов исполняемый `Terminal Eye.command`. Он активирует собственное окружение, находит Homebrew/tmux и запускает отдельную сессию: shell слева, глаз с кнопками справа. Начальный Auto не включает камеру. В левой оболочке `terminal-eye` доступен без ручного source.

Mouse mode, Face mode, Auto mode работают в одном процессе. Клавиши m/f/a или 1/2/3 — запасное управление, q завершает программу. При выходе из Face камера сразу освобождается. Если устройство недоступно, прежний режим сохраняется с явной ошибкой. Текст вставки игнорируется и не может случайно включить камеру.

## Фактически проверено

- **223 теста прошли за 17.34 с.** Проверки написаны с наблюдаемыми red/green для новых функций.
- Полный CLI в реальном PTY: вставка с f/q и вложенным mouse report не открывает камеру; клики Mouse → Face (контролируемое устройство) → Auto не перезапускают процесс. OPEN/CLOSE ровно один раз, q восстанавливает termios и DEC1000/1006/2004.
- **Физическая камера и native MediaPipe:** начальный Auto, явный SGR-клик Face, получен FACE FOUND; клик Auto вызвал close, `cap.isOpened()` стал False до завершения процесса. Auto продолжил работу, q вернул exit 0, экран и termios восстановлены. Кадры не сохранялись.
- Все три native CLI-режима завершились с exit 0: idle — 1.26 с, mouse — 1.37 с, camera — 3.78 с с учётом старта. Курсор и alternate screen восстановлены.
- **Настоящий tmux и подключённый PTY-клиент 120×32:** все подписи отображены, SGR-клики с учётом смещения правой панели переключили Auto → глобальный Quartz Mouse → Auto. Ctrl+B Left/Right менял панель. `terminal-eye --help` работал в левой оболочке без source. q закрыл только глаз; detach завершил launcher с exit 0.
- Реальные изолированные tmux-тесты сохранили старые mouse=off/prefix=C-a и глобальные настройки при успешном запуске и ошибке split. Менялась только новая собственная сессия; временные серверы тестов удалены.
- Независимый обзор подтвердил исправления mono-кнопок и области действия tmux-настроек; других замечаний не осталось.

История первоначального отказа камеры в `VERIFICATION.md` относится к версии 0.2. В текущем прогоне камера уже доступна, FACE FOUND и освобождение устройства подтверждены.

Физическое нажатие мышью в GUI Terminal.app/iTerm2 не автоматизировалось: CUA запрещает управление Terminal.app. Проверен тот же поток SGR/X10-отчётов через реальные PTY и tmux. Визуальная оценка шрифтов/профилей и физические несколько мониторов остаются ручными проверками. При отсутствии mouse reporting используйте m/f/a в панели глаза.
