# Несколько окон, Mouse и палитры · 0.5

22 октября 2026, macOS 26.6.2 arm64, Python 3.12.14, tmux 3.8.

## Результат

Mouse по умолчанию использует собственное окно/панель как точку отсчёта. Режим `--mouse-space screen` оставляет прежние общие координаты. `wall` рассчитывает сетку native-окон и передаёт каждому проверенный CGWindowID; `themes`, восемь палитр и клавиша `t` управляют цветом. `--minimal` сохраняет локальные клавиши без обычного HUD. Камера сама не включается.

**Свежий полный прогон: 335 passed in 19.02s.** Команда: `.venv/bin/python -m pytest -q`. Новые проверки выполнялись red → green; после обзора исправлены скрытое предупреждение с no-controls, гонка статусов tmux/Quartz и очистка временных файлов при таймауте child. Независимый финальный обзор существенных замечаний не оставил.

## Проверки

- Геометрия: один курсор даёт противоположные направления для левого/правого окна; вертикальная ось, отрицательные координаты мониторов, перемещение, стабильность при смене фокуса, идентичность владельца и восстановление пропавшего окна.
- Границы/частота: указатель читается каждый кадр, положение окна не чаще 4 Гц; фоновый ограниченный поиск TTY не задерживает кадры. Отказ Automation/неизвестное окно явно показывают screen fallback, в том числе с minimal/no-controls.
- tmux: cell-геометрия панели, верхняя/нижняя строка статуса, пустые viewport offsets, контрольные и неоднозначные клиенты. Форматы настоящего tmux дополнительно проверены независимым изолированным сервером с подключённым PTY, без GUI.
- Wall: расчёт 3×3, ручные колонки, отсутствие пересечений, доступный экран/Dock/меню, отрицательные и дробные координаты, отказ до запуска при маленьких ячейках/ошибках параметров. Поведение handoff, разрешений, очистки и безопасные Unicode/апостроф/$/backtick пути проверены на контролируемом внешнем запуске.
- `wall --dry-run --count 9 --theme hacker` успешно прочитал реальный NSScreen и выдал девять ячеек 3×3, не открывая окна. Каждый command использует Mouse/window/minimal/12 FPS; реальные рамки подбираются с учётом округления шрифта.
- Оба JXA-скрипта прошли `osacompile -l JavaScript`. Изолированная функция fitWindow выполнена настоящим JXA с fake-window объектом и проверкой повторного подбора рамки. Архивы профиля декодированы настоящим AppKit: Menlo-Regular 10 pt и непрозрачный фон.
- Native PTY: minimal/hacker, реальная клавиша t изменила зелёный на синий, q завершил процесс; настоящий Quartz screen-mode завершился нормально; отсутствующий explicit window ID показал fallback даже с minimal/no-controls. Все три выхода 0, восстановлены курсор, alternate screen и termios. Камера не открывалась.
- Палитры: фактическая доминанта каналов, оттенки серого, яркость hacker выше matrix, более 50 цветовых уровней, сохранение материалов/геометрии, ASCII и blocks. `assets/preview/themes.png` визуально проверен; это растр фактических ANSI-символов, не снимок GUI.
- Compileall, shell-синтаксис и CLI help прошли. Восемь исходных файлов reference сохранены без изменений.

## Ограничения проверки

**Реальное открытие сетки в GUI Terminal.app/iTerm2 не выполнялось.** Tool session запрещает управление Terminal.app; обход через другой инструмент не применялся. Подтверждены расчёт, исполняемые части, компиляция и native-границы, но фактическую обработку профиля/Apple Events и минимум размера окна конкретной версией GUI проверяет первый пользовательский запуск. iTerm2 на этом Mac не установлен; его JXA компилируется без загрузки приложения.

Для создания окон может понадобиться Automation. Служебный профиль Terminal Eye Wall может остаться в списке Terminal; стандартные профили не меняются. Используйте команду wall, а не сохранённый служебный профиль, чья временная команда предназначалась для одного запуска. Каждый вызов создаёт новую сетку; существующие обычные окна не перестраиваются/не закрываются. В случае частичной ошибки уже созданные окна завершаются через q/Ctrl+C. Отказ разрешения не обходится автоматически.

В обычных окнах собственный TTY определяется фоновым AppleScript. При отказе, неподдерживаемом терминале или нескольких tmux-клиентах остаётся явный screen fallback. При необходимости разрешите Automation и перезапустите глаз. tmux использует пропорции ячеек внутри внешней рамки окна: title/tab bar и отступы дают небольшую погрешность центра. Метаданные собираются без скриншотов, Screen Recording и глобального перехвата клавиатуры.
