# Terminal Eye — руководство

Проект находится в `/Users/muratovaslan/StudioProjects/TerminalEye`. Локальное окружение `.venv` с Python 3.12 уже подготовлено. Автозапуск панели в новых окнах Terminal.app/iTerm2 настраивается командой `install-hook --pane`, приведённой ниже; начальный режим Auto, камера выключена. Команды ниже используют его напрямую: активировать окружение вручную не нужно.

Terminal Eye рисует в терминале анимированный глаз из цветных символов. Он моргает и двигается самостоятельно, следует за курсором или за положением лица в камере. В панели tmux слева остаётся обычная командная строка, справа работает глаз.

## Несколько глаз: каждый смотрит на один курсор со своей стороны

В Mouse mode направление теперь считается от собственного окна, а в tmux — от панели глаза. Курсор между двумя окнами: левый глаз смотрит вправо, правый — влево. Изменение фокуса не меняет привязку; после перемещения окна его положение обновляется примерно четыре раза в секунду.

### Девять зелёных окон одной командой

Этот блок открывает **9 отдельных окон Terminal**, сетку 3×3, яркий зелёный `hacker`. Внутри только глаз; камера выключена:

```bash
cd "/Users/muratovaslan/StudioProjects/TerminalEye"
.venv/bin/terminal-eye wall --count 9 --columns 3 --theme hacker
```

Дальше выбирайте нужный вариант. **Каждый вызов `wall` открывает новую сетку**, поэтому сначала завершите ненужные глаза через `q` или `Ctrl+C` в их окнах. Уже открытые обычные окна и задачи не перестраиваются.

| Что открыть | Команда из папки проекта |
|---|---|
| 9 глаз в стиле Matrix | `.venv/bin/terminal-eye wall --count 9 --theme matrix` |
| 4 синих глаза, 2×2 | `.venv/bin/terminal-eye wall --count 4 --columns 2 --theme blue` |
| 6 чёрно-белых, 3×2 | `.venv/bin/terminal-eye wall --count 6 --columns 3 --theme noir` |
| 9 разноцветных | `.venv/bin/terminal-eye wall --count 9 --theme mixed` |
| 12 янтарных, 4×3 | `.venv/bin/terminal-eye wall --count 12 --columns 4 --theme amber` |
| 4 фиолетовых, 2×2 | `.venv/bin/terminal-eye wall --count 4 --columns 2 --theme violet` |
| Другие отступы и 16 FPS | `.venv/bin/terminal-eye wall --count 9 --theme hacker --gap 8 --margin 16 --fps 16` |
| На втором мониторе | `.venv/bin/terminal-eye wall --count 9 --screen 2 --theme matrix` |
| Через установленный iTerm2 | `.venv/bin/terminal-eye wall --count 9 --app iterm --theme hacker` |
| Без слежения, спокойная анимация | `.venv/bin/terminal-eye wall --count 9 --mode idle --theme blue` |
| Полублоки вместо ASCII | `.venv/bin/terminal-eye wall --count 9 --style blocks --theme hacker` |
| Посмотреть расчёт, не открывая окна | `.venv/bin/terminal-eye wall --count 9 --theme hacker --dry-run` |

`--count` принимает 1..36; `--columns` задаёт число колонок, без него выбирается почти квадратная сетка. Реальное количество ограничено размером экрана: если окна меньше 220×160 логических точек, команда предложит уменьшить число окон/отступы. `--gap` — промежуток, `--margin` — отступ от доступного края экрана, в логических точках. Учитываются строка меню и Dock. `--screen` начинается с 1. По умолчанию 12 FPS для нескольких окон.

В выбранном окне: `t` — следующий цвет, `m` — Mouse, `a` — Auto, `f` — явно включить Face/камеру, `q` или `Ctrl+C` — завершить глаз. Сетка использует `--minimal`: кнопки и обычная статусная строка скрыты, клавиши работают. Ошибки и предупреждение о резервном screen-режиме всё равно видны. Для кнопок запускайте обычный `watch` или основной `Terminal Eye.command`.

При первом запуске сетки macOS может запросить **Automation** для управления Terminal/iTerm2; разрешение нужно выдать приложению, из которого запускается команда. В Terminal создаётся собственный профиль **Terminal Eye Wall** с компактным шрифтом; он может остаться в списке профилей. Запускайте сетку командой `wall`, а не служебным сохранённым профилем. Ваши стандартные профили не меняются. В iTerm2 используется отдельная новая сессия с custom command. Команда не требует доступа к записи экрана и не делает скриншоты.

### Mouse mode для обычных окон и tmux

Обычный запуск теперь использует собственное окно:

```bash
"/Users/muratovaslan/StudioProjects/TerminalEye/.venv/bin/terminal-eye" watch --mode mouse --mouse-space window --theme hacker
```

Старое общее направление по экрану можно выбрать явно:

```bash
"/Users/muratovaslan/StudioProjects/TerminalEye/.venv/bin/terminal-eye" watch --mode mouse --mouse-space screen
```

Для обычного ручного запуска выполняется фоновый поиск собственного окна по TTY. Если macOS не разрешает Automation или окно невозможно однозначно определить, появляется **screen fallback**: курсор работает, но направление общее по экрану. Разрешите Automation и перезапустите глаз. `wall` передаёт идентификатор каждого нового окна напрямую, поэтому отдельный поиск по TTY не нужен. `--window-id` — технический параметр для такого запуска, вручную обычно не требуется.

В tmux учитывается относительное положение панели. Если одна сессия одновременно видна в нескольких окнах/клиентах, однозначного положения нет: используется явный screen fallback. Рамка, вкладки и отступы терминала могут давать небольшую погрешность точки отсчёта.

## Быстрый запуск

Дважды щёлкните `Terminal Eye.command` в Finder. Либо выполните:

```bash
"/Users/muratovaslan/StudioProjects/TerminalEye/Terminal Eye.command"
```

Launcher открывает собственную сессию tmux: оболочка слева, глаз справа. Начальный режим — **Auto mode**, камера выключена. Если tmux недоступен, глаз работает в текущем окне; установить tmux можно командой `brew install tmux`.

### Управление глазом

| Кнопка под глазом | Клавиши в панели глаза | Что происходит |
|---|---|---|
| Mouse mode | `m` или `1` | Глаз смотрит на глобальный курсор из своего окна или панели. |
| Face mode | `f` или `2` | Включается камера, глаз следует за положением лица. |
| Auto mode | `a` или `3` | Самостоятельные движения; камера выключается и освобождается. |
| Завершение | `q` или `Ctrl+C` | Процесс глаза завершается, камера освобождается. |

Нажимайте кнопки мышью. Для клавиш сначала выберите панель глаза. Если терминал не передаёт клики, используйте клавиши. При ошибке переключения сохраняется прежний режим и появляется сообщение. Вставленный текст игнорируется и не включает камеру.

### Управление панелями tmux

- `Ctrl+B`, **отпустить обе клавиши**, затем `←` или `→` — выбрать левую или правую панель. Можно просто щёлкнуть нужную панель.
- Перетащить разделитель мышью — изменить ширину панелей.
- `Ctrl+B`, отпустить, затем `D` — отсоединиться от сессии. **Процессы продолжают работать, включённая камера тоже.** Сначала выберите панель глаза и завершите её через `q` или `Ctrl+C`, если глаз больше не нужен.
- После завершения глаза левая оболочка продолжает работать. `exit` в ней завершает эту оболочку; если это последняя панель, сессия закрывается.

Размер изображения подстраивается под панель. Чтобы увидеть больше деталей, увеличьте окно или немного уменьшите шрифт терминала. Если глаз выглядит овальным, настройте `--cell-aspect` при ручном запуске.

## Автозапуск в новых окнах терминала

Установить или повторно включить постоянную панель:

```bash
/Users/muratovaslan/StudioProjects/TerminalEye/.venv/bin/terminal-eye install-hook --pane
```

После этого новая интерактивная zsh в Terminal.app или iTerm2 открывает tmux с оболочкой слева и глазом справа. Глаз стартует в **Auto mode / idle**, с выключенной камерой. Установка сама по себе не закрывает и не перестраивает уже открытые окна; для проверки откройте новое окно или вкладку терминала.

Автозапуск пропускается при SSH, внутри существующего tmux, без интерактивного TTY, при `TERM=dumb` и при установленном `TERMINAL_EYE_DISABLE`. Повторная загрузка настроек в той же оболочке не создаёт ещё одну панель. Внутренняя левая оболочка тоже не запускает глаз рекурсивно.

Вместо постоянной панели можно выбрать короткое вступление, после которого возвращается командная строка:

```bash
/Users/muratovaslan/StudioProjects/TerminalEye/.venv/bin/terminal-eye install-hook
```

Эта команда заменяет управляемый режим автозапуска на intro. Вступление не включает камеру. Чтобы снова получить постоянную панель, повторите `install-hook --pane`.

Отключить будущий автозапуск:

```bash
/Users/muratovaslan/StudioProjects/TerminalEye/.venv/bin/terminal-eye remove-hook
```

Уже работающие сессии остаются открытыми: завершите глаз отдельно через `q` или `Ctrl+C`.

Временно отключить запуск в текущей оболочке и её дочерних процессах:

```bash
export TERMINAL_EYE_DISABLE=1
```

Открыть одну вложенную оболочку с отключённым автозапуском:

```bash
TERMINAL_EYE_DISABLE=1 /bin/zsh -l
```

Убрать временное отключение:

```bash
unset TERMINAL_EYE_DISABLE
```

`unset` разрешает запуск для последующих подходящих оболочек; он не запускает глаз сам. В левой панели tmux переменная отключения задана намеренно, а сам tmux дополнительно защищён от повторного автозапуска.

### Что меняется в настройках оболочки

Команды `install-hook` и `remove-hook` управляют только блоком между маркерами `# >>> terminal-eye startup >>>` и `# <<< terminal-eye startup <<<` в `$ZDOTDIR/.zshrc`, если `ZDOTDIR` задан, иначе в `~/.zshrc`.

Перед первой установкой блока в существующий файл создаётся резервная копия вида `.zshrc.terminal-eye-backup-<число>` рядом с `.zshrc`. Повторная установка или переключение между intro и pane при существующем блоке не создаёт дубликат и новую копию. Удаление блока сохраняет резервную копию и последующие изменения пользователя вне блока. Если затем установить блок заново, может появиться новая резервная копия. Если `.zshrc` был создан самой установкой и после удаления пуст, этот файл удаляется. Права файла и сама символическая ссылка `.zshrc`, если она есть, сохраняются.

Без внешних правок удаление возвращает исходные байты файла. Если после блока добавлена команда, сохраняется нужный перевод строки между ней и прежним текстом. При повреждённых или повторяющихся маркерах команда отказывается менять файл. Резервную копию не нужно возвращать целиком для обычного отключения: используйте `remove-hook`, чтобы сохранить остальные настройки.

В автозапуске панели записан абсолютный путь к `Terminal Eye.command`; launcher использует соседнюю `.venv`. В варианте intro записывается путь к Python окружения. **После перемещения папки или пересоздания `.venv` повторите установку из нового окружения:**

```bash
/Users/muratovaslan/StudioProjects/TerminalEye/.venv/bin/terminal-eye install-hook --pane
```

## Ручной запуск и настройка

Постоянная панель с выбранным начальным режимом:

```bash
/Users/muratovaslan/StudioProjects/TerminalEye/scripts/eye_tmux.sh idle
/Users/muratovaslan/StudioProjects/TerminalEye/scripts/eye_tmux.sh mouse
/Users/muratovaslan/StudioProjects/TerminalEye/scripts/eye_tmux.sh camera
```

Последняя команда явно включает камеру. Каждый запуск создаёт отдельную собственную сессию. Если запускать из tmux, клиент переключается в новую сессию; прежние сессии и их настройки сохраняются.

Запуск в текущей панели или окне, без создания tmux:

```bash
/Users/muratovaslan/StudioProjects/TerminalEye/.venv/bin/terminal-eye watch --mode idle
/Users/muratovaslan/StudioProjects/TerminalEye/.venv/bin/terminal-eye watch --mode mouse
/Users/muratovaslan/StudioProjects/TerminalEye/.venv/bin/terminal-eye watch --mode camera
```

Кнопки позволяют менять режим во время работы. Параметры ниже относятся к конкретному ручному запуску и не сохраняются автоматически в launcher или автозапуске.

| Задача | Пример команды |
|---|---|
| Зеркально изменить движение | `/Users/muratovaslan/StudioProjects/TerminalEye/.venv/bin/terminal-eye watch --mode camera --invert-x` |
| Настроить чувствительность и сглаживание | `/Users/muratovaslan/StudioProjects/TerminalEye/.venv/bin/terminal-eye watch --mode camera --tracking-gain 2.5 --smoothing 0.08` |
| Показать состояние детекции и координаты | `/Users/muratovaslan/StudioProjects/TerminalEye/.venv/bin/terminal-eye watch --mode camera --debug-tracking` |
| Выбрать камеру и детектор | `/Users/muratovaslan/StudioProjects/TerminalEye/.venv/bin/terminal-eye watch --mode camera --camera-index 0 --camera-backend haar` |
| Завершить через 10 секунд | `/Users/muratovaslan/StudioProjects/TerminalEye/.venv/bin/terminal-eye watch --mode idle --seconds 10` |
| Задать размер и частоту кадров | `/Users/muratovaslan/StudioProjects/TerminalEye/.venv/bin/terminal-eye watch --mode idle --width 100 --height 28 --fps 16` |
| Использовать полублоки Unicode | `/Users/muratovaslan/StudioProjects/TerminalEye/.venv/bin/terminal-eye watch --mode idle --style blocks` |
| Изменить тему | `/Users/muratovaslan/StudioProjects/TerminalEye/.venv/bin/terminal-eye watch --mode idle --theme cyber` |
| Убрать цвет | `/Users/muratovaslan/StudioProjects/TerminalEye/.venv/bin/terminal-eye watch --mode idle --mono` |
| Отключить кнопки и локальные клавиши | `/Users/muratovaslan/StudioProjects/TerminalEye/.venv/bin/terminal-eye watch --mode idle --no-controls` |

`--tracking-gain` больше — движения заметнее; по умолчанию 2.5 для лица и 1 для курсора. `--smoothing` задаётся в секундах: меньше — быстрее реакция, `0` — без сглаживания; по умолчанию 0.12. Face mode по умолчанию компенсирует горизонтальное направление сырого кадра фронтальной камеры; Mouse напрямую следует за курсором. `--invert-x` разворачивает движение относительно обычного направления выбранного режима: для камеры, которая уже зеркалит кадр, используйте этот флаг.

Варианты детектора: `auto`, `haar`, `mediapipe`. `auto` предпочитает совместимый установленный MediaPipe и иначе использует Haar. Индекс камеры начинается с `0`; для другого устройства попробуйте `1`. `--seconds` отсчитывает работу после открытия трекера: ожидание разрешения и инициализация камеры в срок не входят.

Стили: `ascii` и `blocks`; темы: `original`, `matrix`, `hacker`, `blue`, `noir`, `amber`, `violet`, `cyber`. `--cell-aspect` задаёт отношение ширины символа к высоте строки, обычно `0.5`. Размер ограничивается доступной панелью. С `--no-controls` выходите через `Ctrl+C`: клавиша `q` отключена вместе с локальным вводом.

## Найти, вернуть или закрыть сессию tmux

Список всех сессий:

```bash
tmux ls
```

Из левой панели можно узнать имя текущей сессии:

```bash
tmux display-message -p '#S'
```

Сессии проекта имеют имена вида `terminal-eye-501-12345-6789`. В следующих командах **замените имя-пример на точное имя нужной сессии из `tmux ls`**. Знак `=` перед именем требует точного совпадения.

Вернуться в отсоединённую сессию из обычного терминала:

```bash
tmux attach-session -t '=terminal-eye-501-12345-6789'
```

Переключиться в неё из другого tmux:

```bash
tmux switch-client -t '=terminal-eye-501-12345-6789'
```

Закрыть конкретную собственную сессию целиком:

```bash
tmux kill-session -t '=terminal-eye-501-12345-6789'
```

Эта команда завершает и глаз, и левую оболочку вместе с её задачами. Сохраните работу, завершите глаз через `q` или `Ctrl+C` и закрывайте только выбранную сессию проекта.

## Камера и приватность

В Auto/idle и Mouse камера не открывается. Она включается только после явного выбора Face, клавиши `f`/`2` или команды с режимом `camera`. Переход в Auto/Mouse и завершение глаза освобождают камеру. Отсоединение от tmux оставляет работающие процессы и камеру активными.

Face mode отслеживает **положение лица**, а не направление взгляда глаз. При потере лица или устаревшем кадре глаз возвращается в центр. В диагностике `FACE FOUND` означает обнаруженное лицо, `NO FACE` — отсутствие детекции, `NO FRAMES` — отсутствие свежих кадров.

Кадры обрабатываются локально в памяти, не сохраняются и не отправляются. Микрофон и запись экрана не используются. Mouse читает координаты курсора, но не нажимает кнопки и не перехватывает клавиатуру глобально. Сетевое соединение нужно для установки зависимостей, а не для работы глаза.

Если камера не открывается, проверьте **System Settings → Privacy & Security → Camera → Terminal / iTerm2** и перезапустите терминал после изменения разрешения. При ручном запуске можно проверить другой индекс или backend, как в примерах выше. Камеру необязательно включать: Auto работает без неё.

## Восстановление окружения и проверки

Текущее окружение уже готово. Следующие команды нужны для новой установки или восстановления `.venv`; не выполняйте их ради обычного запуска.

При отсутствии инструментов установите Python 3.12 и tmux через Homebrew:

```bash
brew install python@3.12 tmux
```

Перейдите в папку один раз; остальные команды этого блока выполняются из неё. Создавайте `.venv` как новое окружение Python 3.12: перенесённое старое окружение лучше пересоздать, поскольку его служебные файлы могут содержать прежние абсолютные пути.

```bash
cd /Users/muratovaslan/StudioProjects/TerminalEye
python3.12 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -e '.[all,mediapipe,dev]'
.venv/bin/python -m pytest -q
.venv/bin/terminal-eye install-hook --pane
```

Команда `venv` предназначена для отсутствующей `.venv`; если повреждённая папка уже существует, сначала уберите её из пути, например переименуйте в Finder. Не переносите её поверх нового окружения. Вариант установки без MediaPipe — `-e '.[all,dev]'`: камера использует Haar. Системный Python 3.9 не подходит; Python 3.12 выбран для совместимости MediaPipe. Не устанавливайте одновременно `opencv-python` и `opencv-contrib-python` в одно окружение: проект использует contrib.

Проверки из любого каталога:

```bash
/Users/muratovaslan/StudioProjects/TerminalEye/.venv/bin/python -m pytest -q /Users/muratovaslan/StudioProjects/TerminalEye/tests
/Users/muratovaslan/StudioProjects/TerminalEye/.venv/bin/python /Users/muratovaslan/StudioProjects/TerminalEye/scripts/render_previews.py
/Users/muratovaslan/StudioProjects/TerminalEye/.venv/bin/python /Users/muratovaslan/StudioProjects/TerminalEye/scripts/benchmark.py
/bin/zsh -n /Users/muratovaslan/StudioProjects/TerminalEye/scripts/eye_tmux.sh
```

`render_previews.py` обновляет материалы в `assets/preview/`, `benchmark.py` выводит замеры и обновляет `assets/preview/benchmark.json`. Подробности устройства и результаты проверок находятся в [README.md](README.md), [VERIFICATION.md](VERIFICATION.md) и [AUTOSTART_VERIFICATION.md](AUTOSTART_VERIFICATION.md).
